# AI Policy Dashboard

An interactive React app that visualizes U.S. AI policy and AI safety positions across states and political affiliations. The dashboard is designed to make it easy to compare how different states and parties approach AI regulation, safety, and governance.

## What it does

- Shows a U.S. map with state-level AI policy status
- Lets users filter the map by party: All, Democratic, or Republican
- Highlights states with a color-coded political lens
- Opens a state detail view for deeper summaries of candidate or policy positions
- presents a simple dashboard layout with summary stats around the map

This project is a front-end prototype for exploring AI policy narratives in the U.S. and is meant as a visual explainer rather than a production data pipeline.

## Tech stack

- React
- Vite
- JavaScript / JSX
- CSS

## Local development

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
```

## Repository purpose

The app is meant to help users explore a public-facing AI policy dashboard that tracks AI safety and regulation themes through a state-by-state political map.
